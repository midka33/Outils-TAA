# Code de conduite

Les contributions à Outils TAA doivent rester professionnelles, constructives et centrées sur la qualité du logiciel.

Sont attendus :

- respect des contributeurs ;
- échanges factuels et bienveillants ;
- critiques orientées vers les solutions ;
- documentation claire des décisions techniques ;
- absence de comportement discriminatoire, agressif ou intimidant.

Les mainteneurs peuvent modérer ou refuser toute contribution qui ne respecte pas ces principes.
