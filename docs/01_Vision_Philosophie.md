# Outils TAA – Developer Handbook
## Chapitre 01 — Vision & Philosophie

Version: 1.0

## 1. Présentation

Outils TAA est une suite d'outils pyRevit développée pour Autodesk Revit 2025.4.

Le projet est conçu comme un logiciel modulaire destiné à automatiser les tâches répétitives de production BIM en agence d'architecture.

## Objectifs

- Productivité
- Fiabilité
- Simplicité
- Performance
- Pérennité

## Philosophie

- Outils TAA est un logiciel, pas une collection de scripts.
- Les modules partagent une architecture commune.
- Les utilisateurs sont des architectes.
- Les interfaces doivent être cohérentes.
- Les bibliothèques communes doivent être privilégiées.

## Compatibilité

- Autodesk Revit 2025.4
- pyRevit 5.x
- Python embarqué par pyRevit

## Vision long terme

Modules prévus :

- Publication
- Calcul
- Contrôle
- Annotation
- BIM
- Utilitaires
- IA
