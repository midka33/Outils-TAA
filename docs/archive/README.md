# Archives documentaires

Ce dossier conserve les documents historiques déplacés lors du nettoyage suivant
la publication de **Outils TAA v1.3.0**.

Ils restent utiles pour comprendre une décision, retrouver une campagne de tests
ou consulter une ancienne release, mais **ils ne décrivent pas nécessairement le
comportement courant**.

Organisation :

- `export/` — anciennes étapes et anciens guides Export remplacés par `docs/09_Export.md` ;
- `export-tests/` — anciennes campagnes, audits et recettes Revit ;
- `plans-de-vente/` — historique détaillé des étapes de développement Plans de vente ;
- `releases/` — tutoriels et dossiers de préparation des anciennes releases.

Le fichier `11_BUGS_Prevention_Registry_TestWave.md` est conservé uniquement
comme historique. Ses identifiants de bugs ne doivent pas être réutilisés :
`docs/11_BUGS_Prevention_Registry.md` est l'unique registre actif.

Pour connaître la documentation de référence, consulter `docs/INDEX.md`.
